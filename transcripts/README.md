# Transcripts — Transkripte

This folder is **gitignored** — files here stay local only and are never pushed to GitHub.

Slow German transcripts are Annik Rubens' copyrighted content. Download them for personal study use only.

## How to Download

Run the fetch script from the repo root:

```bash
./fetch-transcript.sh <episode-number>
# e.g.: ./fetch-transcript.sh 1
```

Or browse manually at https://slowgerman.com and save the transcript text here as:
`transcripts/slowgerman-NNN-title.md`

## How to Use Transcripts

1. Listen to the episode first without reading
2. Listen again while following the transcript
3. Mark words you didn't catch — add them to your vocabulary list
4. Listen one final time without the transcript
