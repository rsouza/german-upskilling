## How to Use This Textbook

This is a living document. It grows lesson by lesson, session by session.

- **Reference section** → browse any time, independent of lessons. Start here.
- **Lessons** → scene-first, 15-min sessions. Work through in order, or follow a real situation.
- **Vocabulary** → master list + topic lists. Add to after every session.

PDFs are locked snapshots. The `.md` files are the source of truth.
