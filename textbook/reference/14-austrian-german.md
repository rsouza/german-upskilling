# Austrian German — Österreichisches Deutsch

This is the reference you'll consult most. Austrian German is different enough from standard German (Hochdeutsch) that it's worth knowing explicitly.

---

## Greetings — Grüße

| Austrian | Standard German | English | When |
|----------|----------------|---------|------|
| **Grüß Gott** | Guten Tag | Good day | formal, all day |
| **Grüß Sie** / **Grüß dich** | Guten Tag / Hallo | Hello | semi-formal/informal |
| **Servus** | Hallo / Tschüss | Hi / Bye | informal, both greeting AND farewell |
| **Hallo** | Hallo | Hi | informal, all ages |
| **Guten Morgen** | Guten Morgen | Good morning | until ~10 am |
| **Mahlzeit** | Mahlzeit | Enjoy your meal / Good day (noon) | at lunch, also sarcastic |
| **Auf Wiedersehen** | Auf Wiedersehen | Goodbye | formal |
| **Auf Wiederschauen** | Auf Wiedersehen | Goodbye | Austrian formal variant |
| **Baba** | Tschüss | Bye | very Viennese informal |
| **Tschau** | Tschüss | Ciao/bye | informal |

> In professional contexts in Vienna: *Guten Morgen* until ~10, then *Grüß Gott* or just *Hallo* depending on company culture. *Baba* only with people you're very close to.

## Everyday Austrian Expressions

| Austrian expression | Meaning | Context |
|--------------------|---------|---------|
| **Passt!** | OK! / That works! / No problem | universal agreement |
| **Passt scho.** | It's fine / That'll do | informal reassurance |
| **Bitte?** (as response to Danke) | You're welcome | very common — don't say *Gern geschehen* |
| **Bitte!** (handing something) | Here you go | with any handover |
| **Na?** | Well? / So? | casual opener, checking in |
| **Na geh!** | Come on! / No way! | surprise or disbelief |
| **Geh bitte!** | Oh come on! / Seriously? | mild frustration or disbelief |
| **Das ist sich ausgegangen.** | It worked out. / It fit. | things going as planned |
| **Das geht sich nicht aus.** | That won't work / There's not enough. | things not fitting |
| **Ich meld mich.** | I'll be in touch. | universal sign-off |
| **Schau ma mal.** | We'll see. / Let's see. | non-committal, very Austrian |
| **Ur-** (prefix) | very / really | *urleiwand* (really cool), *urgut* (really good) |
| **Leiwand** | great / cool | Viennese slang |
| **Oida!** | Man! / Wow! / Dude! | Viennese exclamation (surprise, approval) |
| **Heast!** | Hey! / Listen! | calling attention, Viennese |

## Professional Austrian Context

| Austrian/formal | Meaning |
|----------------|---------|
| **Mit freundlichen Grüßen** | Kind regards (email sign-off) |
| **Hochachtungsvoll** | Yours faithfully (formal letters) |
| **Sehr geehrte/r Frau/Herr…** | Dear Ms./Mr… (formal address) |
| **Liebe Kolleginnen und Kollegen** | Dear colleagues (email opener, very common) |
| **Im Rahmen von…** | In the context of / As part of… |
| **Ich erlaube mir…** | I take the liberty of… (very Austrian formal) |
| **Ich darf kurz berichten…** | Allow me to briefly report… (formal presentations) |

## Austrian vs. German — Key Differences

| Topic | Austria | Germany |
|-------|---------|---------|
| *January* | **Jänner** | Januar |
| *February* | **Feber** (some contexts) | Februar |
| *You're welcome* | **Bitte** | Gern geschehen / Bitte |
| *Goodbye (formal)* | **Auf Wiederschauen** | Auf Wiedersehen |
| *Thank you very much* | **Danke vielmals** | Vielen Dank |
| *Apologies (casual)* | **Bitte, bitte** (dismissive) | Schon gut |
| Decimal separator | **Komma** (1,5) | same |
| Thousands separator | **Punkt** (1.000) | same |
| Date format | **TT.MM.JJJJ** | same |

## Viennese Café Culture (Essential)

| Ordering | German |
|----------|--------|
| A small black coffee | *einen Schwarzen, bitte* |
| A coffee with a little milk | *einen Braunen* |
| A large coffee with milk | *einen Melange* |
| A coffee with whipped cream | *einen Einspänner* |
| Waiter! (lit. "excuse me") | *Zahlen, bitte!* (to pay) / *Entschuldigung!* |
| The bill, please | *Zahlen, bitte!* |
| Together or separate? | *Zusammen oder getrennt?* |

> In Viennese cafés, the waiter brings your coffee on a silver tray with a glass of water. This is called the *Viennese café tradition* — take your time.

## Useful Phrases for Behörden (Bureaucracy)

| German | English |
|--------|---------|
| *Ich brauche eine Bestätigung.* | I need a confirmation. |
| *Welche Unterlagen brauche ich?* | What documents do I need? |
| *Ich habe einen Termin um…* | I have an appointment at… |
| *Können Sie das bitte erklären?* | Could you please explain that? |
| *Ich verstehe das leider nicht.* | I'm afraid I don't understand that. |
| *Wo muss ich unterschreiben?* | Where do I need to sign? |
| *Kann ich das online erledigen?* | Can I handle that online? |
| *Was ist die Frist?* | What is the deadline? |
