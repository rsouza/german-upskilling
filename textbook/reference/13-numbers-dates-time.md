# Numbers, Dates & Time — Zahlen, Datum und Uhrzeit

## Cardinal Numbers — Kardinalzahlen

| 0–10 | | 11–20 | | 21+ | |
|------|--|-------|--|-----|--|
| 0 null | | 11 elf | | 21 einundzwanzig |
| 1 eins (ein-) | | 12 zwölf | | 22 zweiundzwanzig |
| 2 zwei | | 13 dreizehn | | 30 dreißig |
| 3 drei | | 14 vierzehn | | 40 vierzig |
| 4 vier | | 15 fünfzehn | | 50 fünfzig |
| 5 fünf | | 16 sechzehn | | 60 sechzig |
| 6 sechs | | 17 siebzehn | | 70 siebzig |
| 7 sieben | | 18 achtzehn | | 80 achtzig |
| 8 acht | | 19 neunzehn | | 90 neunzig |
| 9 neun | | 20 zwanzig | | 100 hundert |
| 10 zehn | | | | 1000 tausend |

> *eins* → used alone ("Ich habe **eins**.")  
> *ein-* → before nouns ("**ein** Buch, **einen** Kaffee")  
> 21–99: ones + tens joined: *einundvierzig, dreiundsiebzig*

**Larger numbers:**
- 101 → *hundert**eins***
- 200 → *zweihundert*
- 1.000 → *tausend* (note: German uses . as thousands separator, , as decimal)
- 1.500 → *tausendfünfhundert*
- 1.000.000 → *eine Million*

## Ordinal Numbers — Ordinalzahlen

Used for dates, rankings, floors.

**1st–19th:** stem + **-t-** + adjective ending
- 1. → erst- (*der erste, am ersten*)
- 2. → zweit-
- 3. → dritt- (irregular)
- 4. → viert-
- 7. → siebt- (irregular)
- 8. → acht- (no extra t)
- 19. → neunzehnt-

**20th+:** stem + **-st-** + adjective ending
- 20. → zwanzigst-
- 21. → einundzwanzigst-

**Examples:**
- *Heute ist der **erste** März.* — Today is the first of March.
- *Ich wohne im **dritten** Stock.* — I live on the third floor.
- *Mein **zweites** Meeting ist um 14 Uhr.* — My second meeting is at 2 pm.

## Dates — Datum

**Format:** day.month.year (note the dot after ordinal)

| German | English |
|--------|---------|
| *der 1. November* | 1st of November |
| *am 15. März 2026* | on 15 March 2026 |
| *im Jahr 2026* | in the year 2026 |

**Saying dates:**
- *Welches Datum ist heute?* — What's today's date?
- *Heute ist der **vierzehnte** November.* — Today is the fourteenth of November.
- *Das Meeting ist am **zwanzigsten** Dezember.* — The meeting is on the twentieth of December.

**Months:**

| German | English | Austrian note |
|--------|---------|---------------|
| Januar / **Jänner** | January | *Jänner* is preferred in Austria |
| Februar / **Feber** | February | *Feber* heard in Austria |
| März | March | |
| April | April | |
| Mai | May | |
| Juni | June | |
| Juli | July | |
| August | August | |
| September | September | |
| Oktober | October | |
| November | November | |
| Dezember | December | |

**Days of the week:**
Montag, Dienstag, Mittwoch, Donnerstag, Freitag, Samstag (**Sonnabend** in Germany), Sonntag

> *am Montag* = on Monday | *montags* = on Mondays (recurring)

**Seasons:**
Frühling (spring), Sommer (summer), Herbst (autumn), Winter (winter)
*im Frühling, im Sommer, im Herbst, im Winter*

## Clock Time — Uhrzeit

**Formal (24-hour, always correct):**
- 10:00 → *zehn Uhr*
- 14:30 → *vierzehn Uhr dreißig*
- 09:15 → *neun Uhr fünfzehn*
- 23:45 → *dreiundzwanzig Uhr fünfundvierzig*

**Informal (12-hour conversational):**

| Clock | Formal | Informal |
|-------|--------|---------|
| 3:00 | drei Uhr | drei |
| 3:15 | drei Uhr fünfzehn | Viertel nach drei |
| 3:30 | drei Uhr dreißig | halb **vier** (half to four!) |
| 3:45 | drei Uhr fünfundvierzig | Viertel **vor** vier |

> **Austrian vs. German:** In parts of Austria you may hear:  
> *dreiviertel vier* (= 3:45) instead of *Viertel vor vier*  
> *viertel vier* (= 3:15) instead of *Viertel nach drei*

**Asking / telling time:**
- *Wie spät ist es?* — What time is it?
- *Wie viel Uhr ist es?* — What time is it?
- *Es ist halb drei.* — It's half past two.
- *Um wie viel Uhr beginnt das Meeting?* — What time does the meeting start?

**Useful time expressions:**

| German | English |
|--------|---------|
| pünktlich | on time |
| zu spät | late |
| zu früh | early |
| gegen 10 Uhr | around 10 o'clock |
| ungefähr | approximately |
| circa / ca. | approx. |
| von … bis … | from … to … |
