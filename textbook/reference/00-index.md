# Reference — Index and How to Navigate

This is your grammar handbook. Browse it freely — before a lesson, after a lesson, or when something in a conversation confuses you.

## Reading the Tables

- **Nom** = Nominative: the subject of a sentence (*Ich bin hier.*)
- **Akk** = Accusative: the direct object (*Ich kaufe **einen** Kaffee.*)
- **Dat** = Dative: the indirect object or after certain prepositions (*Ich gehe **mit dem** Chef.*)
- **Gen** = Genitive: possession (*das Büro **des** Chefs*)
