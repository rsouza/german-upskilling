# Songs — Lieder

Traditional Austrian and German songs (*Volkslieder*) with English translations, vocabulary notes, and cultural context. All songs here are in the public domain.

**Why songs?** Music helps vocabulary stick. The rhythm and melody create memory hooks that prose can't. These are songs you'll actually encounter in Austrian daily life.
